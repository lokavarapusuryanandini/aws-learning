# AWS Learning & Practice

A structured workspace for learning and practicing AWS services hands-on.

## Structure

| Folder | Topics |
|---|---|
| `compute/` | EC2, Auto Scaling, Load Balancers, AMIs |
| `storage/` | S3, EBS, EFS, Glacier, Storage Gateway |
| `networking/` | VPC, Subnets, Route Tables, Security Groups, NACLs, VPN, Direct Connect |
| `databases/` | RDS, DynamoDB, Aurora, ElastiCache, Redshift |
| `iam-security/` | IAM users/roles/policies, SCP, KMS, Secrets Manager, WAF, Shield |
| `serverless/` | Lambda, API Gateway, Step Functions, EventBridge |
| `containers/` | ECS, EKS, ECR, Fargate |
| `monitoring/` | CloudWatch, CloudTrail, X-Ray, Config, Trusted Advisor |
| `devops-cicd/` | CodeCommit, CodeBuild, CodeDeploy, CodePipeline, CloudFormation, CDK |
| `messaging/` | SQS, SNS, Kinesis, MQ |
| `notes/` | Study notes, cheat sheets, exam prep |

## How to Use

Each folder contains:
- Practice scripts / IaC templates (CloudFormation / CDK)
- CLI command references
- Architecture diagrams or notes

## AWS CLI Quick Setup

```bash
aws configure
# Enter: Access Key ID, Secret Access Key, Region, Output format
```
